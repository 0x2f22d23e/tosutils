# tosutils

Miscellaneous utilities for working with TempleOS files

| Name | Description |
| --- | --- |
| `image2GR` | Convert image files to TempleOS GR format
| `svg2GR` | Converts .svg files generated by Aseprite to TempleOS GR format, preserving palette and transparency
| `templeos-slipstream` | Slipstream tool for the TempleOS Standard ISO image
| `todotz` | Compress file to TempleOS .Z format
